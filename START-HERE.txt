========================================
 CRM 報價管理系統 - Mac 測試版使用說明
========================================

這是一套在自己電腦上執行的系統,不會連到外部網路,
資料全部存在你電腦的資料夾裡。

請依照第一步到第四步做一次(約 10 分鐘),
之後每次使用就只要雙擊啟動。


【第一步】安裝 Java(只需做一次)
----------------------------------------
系統需要 Java 17 才能執行。

1. 先查你的 Mac 是什麼晶片:
     左上角蘋果圖示 -> 關於這台 Mac

2. 打開網址:
     https://adoptium.net/temurin/releases/?version=17

3. 在網頁上選擇:
     Operating System : macOS
     Architecture     : 顯示 Apple M1/M2/M3/M4 -> 選 aarch64
                        顯示 Intel             -> 選 x64
     Package Type     : JDK

4. 下載 .pkg 檔,雙擊安裝,一路按「繼續」即可。

※ 選錯 Architecture 會裝不起來,請務必先確認晶片。


【第二步】解壓縮
----------------------------------------
把收到的壓縮檔解開,建議放在「文件」或「桌面」。

解開後資料夾裡應該有:
     crm.jar
     start-crm.command
     START-HERE.txt          (就是這個檔案)
     data (資料夾)
     uploads (資料夾)


【第三步】解除 Mac 的安全限制(只需做一次)
----------------------------------------
因為這個檔案是從 Windows 電腦傳過來的,macOS 會把它
標記為「來路不明」並且不給執行權限,需要手動解除一次。

1. 打開「終端機」App
   (按 Command + 空白鍵,輸入「終端機」按 Enter)

2. 在終端機裡輸入下面這串,最後要空一格:

     chmod +x

3. 【不要按 Enter】先把 start-crm.command 這個檔案
   從 Finder 視窗「用滑鼠拖曳」進終端機視窗裡放開,
   終端機會自動補上檔案路徑。

4. 這時候再按 Enter。沒有出現任何訊息就是成功了。

5. 接著再輸入下面這串,一樣最後空一格:

     xattr -c

6. 一樣【不要按 Enter】,把 start-crm.command 再拖進去
   一次,然後按 Enter。沒有訊息就是成功了。

7. 終端機可以關掉了。

※ 這兩個指令的意思:
   chmod +x  = 允許這個檔案被執行
   xattr -c  = 清除「從網路下載」的標記
   兩個都只影響這一個檔案,不會動到你電腦其他設定。


【第四步】啟動
----------------------------------------
雙擊 start-crm.command

如果還是被擋下來(顯示「無法打開」),改用:
     對檔案按右鍵 -> 選「打開」-> 警告視窗再按一次「打開」

啟動後會跳出一個「終端機」視窗顯示啟動訊息,
等 5-15 秒,瀏覽器會自動打開系統畫面。

如果瀏覽器沒有自動打開,請手動打開瀏覽器,
在網址列輸入:  http://localhost:8080


【日常使用】
----------------------------------------
啟動:雙擊 start-crm.command
停止:直接關掉那個終端機視窗,或按 Control + C

※ 系統執行期間,那個終端機視窗不能關,關了系統就停了。
※ 第三步只需要做一次,以後不用再做。


【資料存在哪裡】
----------------------------------------
和 start-crm.command 同一個資料夾底下:

  data/crm.db      <- 所有資料都在這個檔案裡
  backup/          <- 備份檔存放處(第一次備份後才會出現)
  uploads/         <- 公司 Logo 等上傳檔

備份方式:在系統的「設定」頁面按「立即備份」,
或直接複製 data/crm.db 這個檔案留存。


【常見狀況】
----------------------------------------
Q: 雙擊沒反應,或說「沒有適當的存取權限」
A: 第三步沒做或沒做完,請重做第三步(兩個指令都要)。

Q: 終端機顯示「找不到 Java」
A: 請回到第一步安裝 Java,裝完後重新打開。

Q: 瀏覽器顯示「無法連線」
A: 伺服器可能還沒完全啟動,等 10 秒後重新整理。
   若終端機視窗已經關掉,請重新啟動系統。

Q: 啟動時說 Port 8080 已被使用
A: 系統已經在跑了,不用再開一次,
   直接打開瀏覽器輸入 http://localhost:8080 即可。

Q: 想換一台電腦繼續用
A: 把整個資料夾(含 data 資料夾)複製過去即可。
