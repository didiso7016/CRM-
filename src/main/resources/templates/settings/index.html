還原說明

還原資料庫請依下列步驟(避免誤操作,不在網頁直接執行):

  1. 關閉本系統(關閉執行視窗)。
  2. 到 backup 資料夾,找到要還原的檔案。
  3. 將它複製到 data 資料夾,並更名為 crm.db(先備份現有的)。
  4. 重新執行 start-crm.bat。

詳細步驟見專案根目錄的 restore-guide.txt。
